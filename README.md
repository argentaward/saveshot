# Saveshot 📸

**Saveshot** — легковесная нативная Windows-утилита, решающая проблему сохранения снимков экрана.

Больше не нужно открывать Paint, чтобы сохранить вырезанную область экрана в файл.  
Вы просто нажимаете привычную комбинацию **`Win + Shift + S`**, выделяете область — и скриншот **мгновенно сохраняется в файл** в выбранную папку.

---

## ✨ Преимущества и особенности

* 🚀 **0% нагрузки на процессор:** работает через нативный Windows API (`AddClipboardFormatListener`), а не через постоянный опрос (polling). Программа спит и пробуждается только в момент появления снимка.
* 🪶 **Ультра-легковесная:** размер `.exe` — всего **~31 КБ**, потребление оперативной памяти — **~10–20 МБ** (Windows автоматически сжимает рабочий набор в трее).
* 📦 **Полная автономность:** не требует установки сторонних библиотек, Python или других пакетов. Работает на любой Windows 10 и 11 «из коробки» (.NET Framework 4.8 встроен в ОС).
* ⚙️ **Запуск вместе с системой:** галочка в настройках прописывает автозапуск в реестр Windows (`HKCU\...\Run`).
* 📁 **Гибкая настройка папки и формата:** выбор любой директории (Рабочий стол, Изображения, проект) и формата (PNG без потерь, JPEG сжатый, BMP).
* 🏷️ **Шаблоны имен:** настраиваемый шаблон имени файла (например, `Screenshot_{date}_{time}.png` с тегами `{date}`, `{time}`, `{yyyy}`, `{MM}`, `{dd}`, `{HH}`, `{mm}`, `{ss}`).
* 🔊 **Приятные звуки Windows:** выбор мягкого клика, мелодичного сигнала или режима без звука (через Win32 API).
* 📋 **Действия с буфером обмена:**
  * Оставить изображение в буфере (по умолчанию).
  * Автоматически скопировать в буфер абсолютный путь к файлу.
  * Поместить в буфер сам файл (`FileDrop`), чтобы сразу вставлять его в Проводник, Telegram, Discord и т.д.
* 🔔 **Уведомления в трее:** клик по всплывающему уведомлению мгновенно открывает папку и подсвечивает сохраненный файл в Проводнике.

## 🚀 Быстрый старт

1. Запустите файл **`Saveshot.exe`**.
2. В системном трее (возле часов) появится значок камеры 📷.
3. Нажмите **`Win + Shift + S`** и выделите любую область экрана.
4. Скриншот мгновенно сохранится в папку `Изображения\Saveshot` (или в ту, которую вы настроите).

## 🛠️ Сборка из исходников

Для сборки не требуется устанавливать Visual Studio. Используется компилятор C#, встроенный в саму Windows:

Запустите файл:
```cmd
build.bat
```
или выполните команду в консоли:
```powershell
& "C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe" /nologo /target:winexe /platform:anycpu /optimize+ /win32icon:app.ico /win32manifest:app.manifest /r:System.dll,System.Drawing.dll,System.Windows.Forms.dll /out:Saveshot.exe src\*.cs
```
